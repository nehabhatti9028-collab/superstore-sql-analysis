# Superstore SQL Analysis

SQL analysis of a retail Superstore dataset to understand sales, profit, customers and products over time.

## Dataset
- Source: Kaggle, "Superstore Dataset" (Vivek Chowdhury)
- 9,994 orders, 21 columns

## Tools
Python, SQL (SQLite), Pandas, Google Colab

## SQL concepts used
SELECT, GROUP BY, HAVING, ORDER BY, LIMIT, aggregate functions (SUM, ROUND)

## Questions answered
1. Sales and profit by category
2. Top 10 customers by total spend
3. Sales and profit by year
4. Sub-categories that make a loss
5. Top 5 products by profit

## Key Insights
1. Sales grew about 1.5x from 2014 to 2017 and profit about 1.9x.
2. Profit margin rose from about 10% (2014) to about 12.7% (2017).
3. Only 3 sub-categories lose money: Tables, Bookcases and Supplies.
4. Tables have the biggest loss (-17.7K) despite over 2 lakh in sales.
5. Top customer spent over 25K. The top profit product is a Canon copier (about 25K profit).
